Payment Gateway Demo

Пет-проект демонстрационной платёжной системы с полной интеграцией онлайн-оплаты (ЮKassa) и локальным эмулятором платёжного шлюза. Каталог товаров захардкожен для демонстрации процесса оплаты.

Ключевая особенность: валидация карт по алгоритму Луна на клиенте. Клиент проверяет номер карты локально, определяет outcome (success/fail) и отправляет на сервер только cardLast4 (4 последние цифры). Полные реквизиты карт никогда не покидают браузер — PCI DSS compliant архитектура.
