# Портфолио Frontend Developer

## 📌 О проекте

Персональное портфолио-резюме фронтенд-разработчика. Одностраничный сайт, демонстрирующий навыки, проекты и опыт работы.

**Технологии:** HTML5, CSS3, Vanilla JavaScript (без фреймворков)

## ✨ Особенности

### 🎨 Дизайн
- Тёмная тема с акцентным синим цветом (#3b82f6)
- Адаптивная вёрстка (desktop → tablet → mobile)
- Шрифты: Inter (текст) + JetBrains Mono (код)
- Иконки: Font Awesome 6

### 🎬 Анимации
- **Matrix Rain** — падающие зелёные символы на фоне hero-секции
- **Typing Effect** — текст "Frontend Developer" печатается при появлении в viewport
- **Scroll Animations** — секции плавно появляются при прокрутке
- **Прогресс-бар навыков** — визуализация уровня владения технологиями
- **Пульсирующая рамка** аватарки с градиентом
- **Hover-эффекты** на карточках проектов

### 📱 Адаптивность
- Desktop: 1024px+ (3 колонки)
- Tablet: 768-1024px (2 колонки)
- Mobile: < 768px (1 колонка)

## 🚀 Оптимизации

### Производительность
- **Matrix Rain** использует `requestAnimationFrame` вместо `setInterval`
- Матрица останавливается, когда hero-секция не видна (Intersection Observer)
- Scroll-события с throttle (100ms) для прогресс-бара
- CSS-анимации вместо JS (GPU-ускорение)

### Размер
- ~250 строк HTML
- ~650 строк CSS
- ~180 строк JS
- Без зависимостей (CDN только для шрифтов и иконок)

## 🔧 Установка

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере
3. Для локальной разработки: `npx http-server`

## 📝 Кастомизация

### Изменить фото
Замените `images/avatar.jpg` на своё фото

### Обновить навыки
Редактируйте список в `index.html` (секция `.skill-list`)

### Настроить цвета
В `css/style.css` измените CSS-переменные:
```css
:root {
    --color-accent: #3b82f6;
    --color-bg: #0f172a;
    /* ... */
}
```
